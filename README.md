# Updated-Portfolio
# 👨‍💻 Personal Portfolio Website

Welcome to my official portfolio! This website is designed to showcase my skills, projects, and journey as a Frontend Developer. The design focuses on a **Premium Glassmorphism Aesthetic**, smooth user interactions, and a fully responsive layout.

## 🚀 Live Demo
Check out the live version here: **updated-portfolio-by-aabidnation.netlify.app**

## ✨ Key Features
* **💎 Glassmorphism Design:** Modern frosted glass effects using backdrop-filters.
* **🎨 Premium Animations:** Smooth fade-ins, scroll reveals, and 3D tilt effects on cards.
* **📱 Fully Responsive:** Works perfectly on Mobile, Tablet, and Desktop.
* **🌑 Dark Theme:** High-contrast dark UI with vibrant gradient accents.
* **🖱️ Interactive Elements:** Custom cursor and magnetic hover effects.

## 🛠️ Tech Stack
* **Structure:** HTML5
* **Styling:** CSS3 (Flexbox, Grid, CSS Variables, Animations)
* **Logic:** Vanilla JavaScript (Intersection Observer, DOM Manipulation)

## 📂 Sections Included
1.  **Hero Section:** Animated introduction with a gradient blob background.
2.  **About Me:** Professional bio with a 3D tilt-effect profile card.
3.  **Projects:** Showcase of my work (Spotify Clone, E-commerce App, etc.).
4.  **Contact:** A stylized glass-effect contact form.
